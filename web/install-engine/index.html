Install Fedmich Search Engine

Follow the instructions below to add Fedmich as your default search engine.

For Google Chrome

  1. Open Chrome and go to Fedmich.com.
  2. Right-click on the address bar and select Add as search engine.
  3. Alternatively, you can visit Settings > Search engine > Manage search engines and add it manually.
  4. Enter the following details:
    • Name: Fedmich
    • Keyword: fedmich
    • URL with %s in place of query: https://fedmich.com/search?q=%s
